# Portfolio - Renato Lopes

Personal portfolio website of **Renato Lopes**, built with plain HTML, CSS and JavaScript (no build step).

## Sections

- Hero with typing effect
- About
- Skills
- Projects
- Contact

## Run locally

Just open `index.html` in your browser, or serve the folder:

```bash
npx serve .
```

## Customize

Search for `TODO` in `index.html` to find the places to fill in with your own info
(bio, photo, skills, projects, LinkedIn). Colors live in the `:root` variables at the top of `styles.css`.
